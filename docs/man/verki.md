# verki(1)

## NAME

verki - Verki — AI-helpita generado kaj reskribo de teksto.

## SYNOPSIS

```
autish verki [SUBCOMMAND] [OPTIONS]...
```

## DESCRIPTION

Verki — AI-helpita generado kaj reskribo de teksto.

For more information about autish, see autish(1).

## SUBCOMMANDS

- `generi  Generate or rewrite text with AI.`
- `modelo  Browse available models from the provider.`


## OPTIONS

Run `autish verki --help` to see all available options.

## EXAMPLES

```bash
# Show help for this command
autish verki --help

# Show help for a specific subcommand
autish verki SUBCOMMAND --help
```

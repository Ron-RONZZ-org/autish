# kontakto(1)

## NAME

kontakto - Administri kontaktojn.

## SYNOPSIS

```
autish kontakto [SUBCOMMAND] [OPTIONS]...
```

## DESCRIPTION

Administri kontaktojn.

For more information about autish, see autish(1).

## SUBCOMMANDS

- `listigi`
- `vidi`
- `serci`
- `aldoni`
- `modifi`
- `forigi`
- `purigi`
- `malfari`
- `kategorio  Administri kontaktajn kategoriojn.`


## OPTIONS

Run `autish kontakto --help` to see all available options.

## EXAMPLES

```bash
# Show help for this command
autish kontakto --help

# Show help for a specific subcommand
autish kontakto SUBCOMMAND --help
```

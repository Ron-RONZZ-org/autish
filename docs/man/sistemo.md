# sistemo(1)

## NAME

sistemo - Sistemaj utilaĵoj: informoj kaj bash alias-oj.

## SYNOPSIS

```
autish sistemo [SUBCOMMAND] [OPTIONS]...
```

## DESCRIPTION

Sistemaj utilaĵoj: informoj kaj bash alias-oj.

For more information about autish, see autish(1).

## SUBCOMMANDS

- `info        Montri sistemajn informojn.`
- `install     Instali autish ĝlobale por ke aliaj komandoj kaj bash-alias-oj funkciu.`
- `bash-alias  Administri bash alias-ojn.`


## OPTIONS

Run `autish sistemo --help` to see all available options.

## EXAMPLES

```bash
# Show help for this command
autish sistemo --help

# Show help for a specific subcommand
autish sistemo SUBCOMMAND --help
```

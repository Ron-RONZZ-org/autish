# shelo(1)

## NAME

shelo - Startigi interagan autish-ŝelon (ne necesas tajpi 'autish' ĉiufoje).

## SYNOPSIS

```
autish shelo [SUBCOMMAND] [OPTIONS]...
```

## DESCRIPTION

Startigi interagan autish-ŝelon (ne necesas tajpi 'autish' ĉiufoje).

For more information about autish, see autish(1).

## SUBCOMMANDS

- See `autish {cmd} --help` for available subcommands


## OPTIONS

Run `autish shelo --help` to see all available options.

## EXAMPLES

```bash
# Show help for this command
autish shelo --help

# Show help for a specific subcommand
autish shelo SUBCOMMAND --help
```

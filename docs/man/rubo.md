# rubo(1)

## NAME

rubo - Administri la rikirejon (rubujon) — movo, reparo, serĉo de forigitaj dosieroj.

## SYNOPSIS

```
autish rubo [SUBCOMMAND] [OPTIONS]...
```

## DESCRIPTION

Administri la rikirejon (rubujon) — movo, reparo, serĉo de forigitaj dosieroj.

For more information about autish, see autish(1).

## SUBCOMMANDS

- `forigi        Movi dosierojn al rikirejon (recycle bin).`
- `rm            Movi dosierojn al rikirejon (recycle bin). Alias por 'rubo forigi'.`
- `ls            Listigi dosierojn en la rikirejon.`
- `serci         Serĉi en la rikirejon.`
- `restarigi     Restarigi dosierojn el la rikirejon.`
- `rs            Restarigi dosierojn el la rikirejon. Alias por 'rubo restarigi'.`
- `forigi-cxape  Ĉapele foriĝi dosierojn el la rikirejon.`


## OPTIONS

Run `autish rubo --help` to see all available options.

## EXAMPLES

```bash
# Show help for this command
autish rubo --help

# Show help for a specific subcommand
autish rubo SUBCOMMAND --help
```

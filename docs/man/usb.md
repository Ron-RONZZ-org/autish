# usb(1)

## NAME

usb - Komandoj por administri USB-aparatojn.

## SYNOPSIS

```
autish usb [SUBCOMMAND] [OPTIONS]...
```

## DESCRIPTION

Komandoj por administri USB-aparatojn.

For more information about autish, see autish(1).

## SUBCOMMANDS

- `ls          List USB devices.`
- `konekti     Bind a USB device to its driver.`
- `malkonekti  Unbind a USB device from its driver.`


## OPTIONS

Run `autish usb --help` to see all available options.

## EXAMPLES

```bash
# Show help for this command
autish usb --help

# Show help for a specific subcommand
autish usb SUBCOMMAND --help
```

# taglibro(1)

## NAME

taglibro - Taglibro — administri taglibrajn enirojn kun etikedoj.

## SYNOPSIS

```
autish taglibro [SUBCOMMAND] [OPTIONS]...
```

## DESCRIPTION

Taglibro — administri taglibrajn enirojn kun etikedoj.

For more information about autish, see autish(1).

## SUBCOMMANDS

- `aldoni  Aldoni taglibran eniron.`
- `serci   Serĉi taglibrajn enirojn per kombineblaj filtriloj.`
- `vidi    Montri unu taglibran eniron laŭ UUID aŭ titolo.`
- `modifi  Modifi ekzistantan taglibran eniron.`
- `forigi  Forigi taglibran eniron laŭ UUID aŭ titolo.`


## OPTIONS

Run `autish taglibro --help` to see all available options.

## EXAMPLES

```bash
# Show help for this command
autish taglibro --help

# Show help for a specific subcommand
autish taglibro SUBCOMMAND --help
```

# uzanto(1)

## NAME

uzanto - Uzanto — administri uzantprofilon kaj ĉefpasvorton.

## SYNOPSIS

```
autish uzanto [SUBCOMMAND] [OPTIONS]...
```

## DESCRIPTION

Uzanto — administri uzantprofilon kaj ĉefpasvorton.

For more information about autish, see autish(1).

## SUBCOMMANDS

- `pasvorto  Set (or remove) the user master password.`
- `profilo   Administri uzantprofilon (profilo).`


## OPTIONS

Run `autish uzanto --help` to see all available options.

## EXAMPLES

```bash
# Show help for this command
autish uzanto --help

# Show help for a specific subcommand
autish uzanto SUBCOMMAND --help
```

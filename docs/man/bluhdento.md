# bluhdento(1)

## NAME

bluhdento - Komandoj por administri Bluetooth-aparatojn.

## SYNOPSIS

```
autish bluhdento [SUBCOMMAND] [OPTIONS]...
```

## DESCRIPTION

Komandoj por administri Bluetooth-aparatojn.

For more information about autish, see autish(1).

## SUBCOMMANDS

- `ls          List paired Bluetooth devices, with connected ones first.`
- `konekti     Connect a paired Bluetooth device.`
- `malkonekti  Disconnect a Bluetooth device, or all connected devices if no MAC is given.`


## OPTIONS

Run `autish bluhdento --help` to see all available options.

## EXAMPLES

```bash
# Show help for this command
autish bluhdento --help

# Show help for a specific subcommand
autish bluhdento SUBCOMMAND --help
```

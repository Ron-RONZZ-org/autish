# todo(1)

## NAME

todo - Todo — administri taskojn kun etikedoj kaj prioritato.

## SYNOPSIS

```
autish todo [SUBCOMMAND] [OPTIONS]...
```

## DESCRIPTION

Todo — administri taskojn kun etikedoj kaj prioritato.

For more information about autish, see autish(1).

## SUBCOMMANDS

- `aldoni  Aldoni novan todo-taskon.`
- `serci   Serĉi todo-taskojn per kombineblaj filtriloj.`
- `vidi    Montri unu todo-taskon laŭ UUID aŭ titolo.`
- `modifi  Modifi ekzistantan todo-taskon.`
- `forigi  Forigi todo-taskon laŭ UUID aŭ titolo.`


## OPTIONS

Run `autish todo --help` to see all available options.

## EXAMPLES

```bash
# Show help for this command
autish todo --help

# Show help for a specific subcommand
autish todo SUBCOMMAND --help
```

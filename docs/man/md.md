# md(1)

## NAME

md - Markdown-iloj: vidi en retumilo, eksporti kaj importi.

## SYNOPSIS

```
autish md [SUBCOMMAND] [OPTIONS]...
```

## DESCRIPTION

Markdown-iloj: vidi en retumilo, eksporti kaj importi.

For more information about autish, see autish(1).

## SUBCOMMANDS

- `vidi      Render a Markdown file in the default browser.`
- `eksporti  Export a Markdown file as HTML or PDF.`
- `importi   Convert a document (docx/pdf/html/odt/xml/tex) to Markdown.`


## OPTIONS

Run `autish md --help` to see all available options.

## EXAMPLES

```bash
# Show help for this command
autish md --help

# Show help for a specific subcommand
autish md SUBCOMMAND --help
```

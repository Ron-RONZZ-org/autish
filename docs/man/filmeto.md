# filmeto(1)

## NAME

filmeto - Filmeto — trankvila navigado de filmetoj (nun: YouTube).

## SYNOPSIS

```
autish filmeto [SUBCOMMAND] [OPTIONS]...
```

## DESCRIPTION

Filmeto — trankvila navigado de filmetoj (nun: YouTube).

For more information about autish, see autish(1).

## SUBCOMMANDS

- `kuketoj-helpo  Montri detalajn instrukciojn por YouTube-kuketoj kaj profiloj.`
- `agordi         Montri aŭ agordi defaŭltojn por filmeto.`
- `serci          Serĉi YouTube-filmetojn laŭ pluraj kriterioj.`
- `vidi           Elŝuti filmeton al /tmp kaj malfermi en defaŭlta video-ludilo.`
- `elsuti         Elŝuti filmetojn/playlistojn kun difinita kvalito.`


## OPTIONS

Run `autish filmeto --help` to see all available options.

## EXAMPLES

```bash
# Show help for this command
autish filmeto --help

# Show help for a specific subcommand
autish filmeto SUBCOMMAND --help
```

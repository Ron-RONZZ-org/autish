# kp(1)

## NAME

kp - Ruli komandon kaj kopii ĝian eligon al tondujo.

## SYNOPSIS

```
autish kp [SUBCOMMAND] [OPTIONS]...
```

## DESCRIPTION

Ruli komandon kaj kopii ĝian eligon al tondujo.

For more information about autish, see autish(1).

## SUBCOMMANDS

- See `autish {cmd} --help` for available subcommands


## OPTIONS

Run `autish kp --help` to see all available options.

## EXAMPLES

```bash
# Show help for this command
autish kp --help

# Show help for a specific subcommand
autish kp SUBCOMMAND --help
```

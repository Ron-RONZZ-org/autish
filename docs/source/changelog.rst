Changelog
=========

All notable changes to autish will be documented in this file.

The format is based on `Keep a Changelog <https://keepachangelog.com/>`_,
and this project adheres to `Semantic Versioning <https://semver.org/>`_.

[0.0.1] - 2026-04-28
-----------------------

Initial pre-alpha release.

Added
~~~~~~

* **Core CLI framework** — Typer-based CLI with 22 commands
* **Esperanto command names** — All CLI keywords in Esperanto
* **i18n support** — Esperanto, English, French locales
* **Time display** (``tempo``) — Show current time and day of week
* **Wi-Fi management** (``wifi``) — List, connect, disconnect, forget networks
* **Bluetooth management** (``bluhdento``) — List, connect, disconnect devices
* **System information** (``sistemo``) — Display system info
* **Clipboard** (``kp``) — Copy command output to clipboard
* **Shell execution** (``shelo``) — Execute shell commands
* **Personal wordbook** (``vorto``) — SQLite-backed vocabulary manager
* **Knowledge base** (``encik``) — Personal encyclopedia with Wikidata integration
* **Email management** (``retposto``) — Local email client
* **Contact management** (``kontakto``) — Contact database with vCard export
* **Document management** (``doc``) — Documentation library
* **Markdown utilities** (``md``) — Markdown processing tools
* **Backup management** (``sekurkopio``) — Backup and restore
* **User profiles** (``uzanto``) — User settings and preferences
* **AI text generation** (``verki``) — AI-assisted text generation via Hugging Face
* **Task management** (``todo``) — Task tracker with status workflow
* **Calendar** (``kalendaro``) — Calendar application
* **Disk management** (``disko``) — Disk and partition tools
* **USB management** (``usb``) — USB device management
* **Video/media** (``filmeto``) — Video and media management
* **Tag/label** (``etikedo``) — Tag and label management
* **Daily journal** (``taglibro``) — Daily journal with date-based entries
* **Recycle/trash** (``rubo``) — Recycle bin management
* **SQLite microapps** — WAL journal mode, optimized queries
* **Rich output** — Calm, minimal output with Rich library
* **Bash aliases** — Automatic bash alias generation
* **Offline-first design** — Core functionality works without internet

Commands Reference
==================

autish provides 22 commands for essential desktop and information management
tasks. All command names and long option names are in **Esperanto**.

Command Categories
------------------

**Microapps** (with persistent SQLite databases):

* :doc:`vorto <vorto>` — Personal wordbook
* :doc:`encik <encik>` — Knowledge base
* :doc:`retposto <retposto>` — Email management
* :doc:`kontakto <kontakto>` — Contact management
* :doc:`taglibro <taglibro>` — Daily journal
* :doc:`todo <todo>` — Task management
* :doc:`kalendaro <kalendaro>` — Calendar

**System Tools**:

* :doc:`tempo <tempo>` — Time display
* :doc:`wifi <wifi>` — Wi-Fi management
* :doc:`bluhdento <bluhdento>` — Bluetooth management
* :doc:`sistemo <sistemo>` — System information
* :doc:`disko <disko>` — Disk management
* :doc:`usb <usb>` — USB device management

**Utilities**:

* :doc:`kp <kp>` — Clipboard copy
* :doc:`shelo <shelo>` — Shell command execution
* :doc:`md <md>` — Markdown utilities
* :doc:`doc <doc>` — Documentation management
* :doc:`sekurkopio <sekurkopio>` — Backup management
* :doc:`uzanto <uzanto>` — User profile settings
* :doc:`verki <verki>` — AI-assisted text generation
* :doc:`filmeto <filmeto>` — Video/media management
* :doc:`etikedo <etikedo>` — Tag/label management
* :doc:`rubo <rubo>` — Recycle/trash management
